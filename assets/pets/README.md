# Assistant pet assets

These bundled animation strips are generated by `tool/generate_pet_assets.py`.
The script pins each source revision, aligns every pose to a shared stage and
baseline, and derives the quiet idle strips from source frames. Runtime timing
is defined in `lib/widgets/assistant_pet.dart`, and only the selected pet's
current and near-future strips are kept decoded.
