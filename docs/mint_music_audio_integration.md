# 薄荷音乐参考与音频设置集成

参考仓库：https://github.com/kingmuchen/Mint-Music ，检查日期：2026-09-07。

## 本次落地

- 原播放页字号按钮替换为全局音质。字号、行距移到配置页的“歌词显示”，沿用已有保存键。
- 网易云与 QQ/酷狗保留各自的全局目标音质，B站保留独立音频流偏好。当前歌曲重新解析并保留进度和播放/暂停状态，后续播放、重启及切换用户继续使用已保存设置。
- 音质是解析目标，不保证第三方音源一定返回同等级文件；既有自动降级策略继续有效。B站单曲缺少目标流时不再覆盖全局偏好。
- 缓存记录解析目标音质。不同目标及旧版没有音质标记的缓存不冒充新设置；重新获取成功才替换旧缓存，下载失败保留旧文件。切换后重新播放首次可能需要联网。
- 歌词栏底部增加全局音效：10段均衡器及预设、低音增强、环绕、声道平衡、恢复原声。竖屏在歌词视图下可用。
- 音效作用于应用的音乐播放器，包括后台播放、不同平台歌曲及本地音频缓存；不修改原音频文件，不影响助手播报、独立 MV 视频内核或其他应用。
- 音效保存在全局配置，纳入现有备份恢复。保存失败回退内存偏好，关闭页面不创建新的播放器。

## 平台与资源边界

参考 `lib/features/player/platform/audio_effect_service.dart` 和 Android `MainActivity.kt` 的系统音效方案，使用 Android SDK 现有引擎，没有新增运行时音频依赖。

- 原生处理器绑定 Flutter 引擎和当前音乐 audio session；换会话、用户退出和引擎销毁时释放资源，Activity 旋转不重建音效。
- Android 厂商的均衡器频段数不一致，按设备真实中心频率插值映射10段设置；不直接取设置数组前几个值。
- 声道平衡需 Android 9+ 且设备支持 DynamicsProcessing。仅衰减另一声道，使用该 API 的 dB 单位，关闭默认压缩器和限幅器。
- 设备不支持某项时反馈具体项目，其他音效仍可用；平台调用有超时，参数更新合并为至多一个正在执行和一个最新待处理值。
- 薄荷音乐当前 iOS handler 实际为 no-op。本次不继承“成功但无效果”的行为，iOS/非 Android 明确显示不支持并禁用启用入口。
- Widget/平台通道测试和 Android Kotlin 编译可验证软件路径，但不能替代车机扬声器、蓝牙耳机、厂商音效引擎的真机听感验证。

## 其他可借鉴项

1. 睡眠定时：已移植。播放页定时按钮支持 5-120 分钟、常用时长和播完当前歌曲停止；关闭页面继续计时，停止播放、退出及切换用户取消。不会恢复上次进程的旧定时。
2. 本地音乐库已移植：配置页“音乐库”进入，Android MediaStore 只读扫描，分批查询、最多 5000 首，支持搜索、播放全部、收藏和队列；权限拒绝或撤销可恢复，退出页面取消查询。只接受 MediaStore 音频 URI，不读取任意文件/内容提供器，本地播放不走在线解析。收藏和播放记录仅保存本机引用，跨设备备份不传输音频文件。
3. 逐字与双语歌词：已移植为配置页“逐字高亮”和“显示译文”两个全局开关，默认关闭，随备份恢复。复用 YRC/QRC/KRC 时间轴，仅高亮有可信时间范围的字词，不拆分猜测词内时间；普通或异常时间轴继续整行高亮。使用纯 Flutter，只有活动歌词监听现有播放进度，不增加 WebView 或动画定时器。
4. 全屏歌词模式：已移植。横屏顶部切换键隐藏封面，保留进度、播放、收藏、队列、MV、音质及音效；旋转不丢失模式，返回键优先退出全屏歌词。

其余项目按功能独立移植和提交。音源自动回退本项目已有；JS 插件执行涉及新的安全边界，不直接搬入。

## 下载管理

- 已独立移植。播放页下载菜单可加入当前歌曲或进入下载管理；配置页音乐库也有入口。
- 默认仅 Wi-Fi，切换网络时中断下载并等待 Wi-Fi；单任务串行，最多100条、每首256MB、每次10分钟。暂停/重试从头下载，不伪装为断点续传。
- 下载使用任务独立的音源解析实例，边播边下载不会互相取消；暂停、删除和退出会主动取消解析及原生标签写入。重复关闭只清理一次，删除期间不能重新加入同一任务。
- 已完成和全部任务分开查看，支持取消、重试、离线播放和确认删除。离线歌曲在队列/历史恢复时仍只读取下载文件，不隐式联网。
- 音频存入按用户隔离的应用文档目录，与自动缓存分开。清缓存不删除下载；移除下载只删除受管理的文件，删除用户清理其下载目录。未完成任务重启后暂停，切换用户和退出取消。
- 支持 Android MP3/FLAC/M4A/OGG 等格式的标题、歌手、专辑、歌词和封面写入。使用从 LGPL 源码编译的 Jaudiotagger；先复制到临时副本，标签不支持或失败则保留原始下载并显示提示，绝不修改原本地音乐。歌词与封面同时保留伴随文件；无歌词或封面时不捏造数据。
- 下载索引和文件留在当前设备，不作为云备份音频传输；应用数据清除或卸载会移除应用文档目录中的下载。不能把它当作系统公共 Music 文件夹导出。
- iOS/桌面没有本次 Android 网络和标签平台实现；仅 Wi-Fi 无法确认时不会启动任务，关闭仅 Wi-Fi 后可使用文件下载，标签不处理。
